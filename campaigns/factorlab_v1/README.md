# Neural FactorLab v1

Neural FactorLab replaces the rejected tabular-centered v0 design. Its learner
state is continuous and procedural, its suite task kernel is nonlinear and
hidden, and its executable candidate contract requires a compact neural model
manifest plus bounded binary checkpoints.

`definition.json` is the campaign envelope. A tier is admitted only after the
preregistered study produces a reviewed, immutable qualification report with
all evidence gates verified. Unsupported task combinations are rejected at
preflight rather than described ambiguously as benchmark results.
